# SIPE — Sistema Inteligente de Planejamento e Gestão Escolar

Sistema desenvolvido para apoiar o **planejamento e a gestão escolar**, oferecendo recursos voltados à organização das atividades pedagógicas e ao acompanhamento das informações escolares.

## Sobre o projeto

O SIPE — Sistema Inteligente de Planejamento e Gestão Escolar — é um projeto acadêmico de desenvolvimento de software.

O sistema tem como objetivo apoiar professores e gestores/coordenadores pedagógicos no planejamento, organização e gestão das atividades escolares.

## Objetivos

O projeto busca desenvolver uma solução que contribua para:

- organização do planejamento escolar;
- apoio às atividades pedagógicas;
- gestão das informações escolares;
- acompanhamento dos planejamentos;
- utilização de recursos de inteligência artificial previstos no escopo;
- geração e organização de informações para acompanhamento pedagógico.

## Escopo

O escopo oficial do sistema é definido pelos requisitos funcionais e não funcionais documentados no repositório:

**`sipe-documentacao`**

A documentação oficial deve ser consultada antes da implementação de novas funcionalidades.
